# iPad：从 ChatGPT 到复习台，再到 Obsidian

不必在 iPad 安装 Node。最少步骤是：**复制统一提示词 → 生成JSON → 在有执行能力的ChatGPT中运行校验脚本 → 导入复习台 → 导出“资料JSON” → 数学学习桥导入。** 已有插件可以继续使用，这套工具不要求安装0.1.1。

## 1. 复制提示词与提供资料

在 Safari 打开本分支的 [chatgpt-learning-prompt.md](chatgpt-learning-prompt.md)，复制“开始复制”至“复制结束”之间的内容，粘贴进一个新的 ChatGPT 学习窗口。若GitHub阅读页不方便选择文字，可打开该文件的Raw视图再复制。

开头补一句，例如：

> 本窗口学习数学分析的数列极限；请使用以下统一规范，先讲基础与推导，再整理本次内容。附件是我已有的JSON和本章讲义，请沿用旧ID。

其他15个窗口使用相同提示词，只改变负责主题与实际附件。不能以为一个窗口自动知道另一个窗口的作答。若没有旧JSON，用新主题ID；有旧资料时先提供它。

生成附件后保存到iPad“文件”。如果只有代码块，复制从第一个`{`到最后一个`}`的JSON本体，不含三反引号；现有复习台v2有“粘贴JSON”入口，无需为了手工存文件而安装编辑器。

## 2. 真正运行检查

下载 [validate-math-review.cjs](../scripts/validate-math-review.cjs)（可在GitHub文件页用Raw另存文件）。把脚本和生成JSON一并附到**能够执行代码、并具备Node.js的ChatGPT窗口**，发送：

> 请实际运行附件中的校验器：`node validate-math-review.cjs 我的文件.json`。文件名按附件实际名称处理。给出命令、退出码与错误输出；有错误请依据真实资料修正再运行。不要把目测检查称为脚本校验。若环境无Node，请明确写“未运行”，不要编造成功结果。不要上传我的学习资料到GitHub。

当前交付已经实际运行了这个脚本和自动测试；其他窗口的执行能力不保证相同。若那个窗口不能执行，可以把JSON回传到本任务窗口做检查，或使用下一节的浏览器工具。仅说“检查过了”而没有真实执行结果不算通过。

多窗口需要跨章关联时，一起提供相关当前版本，运行：

```sh
node validate-math-review.cjs window01.json window02.json --out combined.math-review.json
```

- `PASS` / 退出码0：结构通过。多文件只导入生成的`combined.math-review.json`。
- 退出码1：JSON或内容结构错误，按报告的路径修正，例如`/nodes/4/parentId`。
- 退出码2：命令或文件读写问题，例如路径不存在、输出文件已经存在。换新输出文件名，不覆盖原稿。
- 数学推导、题目出处和个人诊断仍要阅读核对；机器校验不能替代这些判断。

电脑或已有Node环境只需下载/克隆本分支，不需要`npm install`。在仓库根目录运行上述命令时，脚本路径改为`scripts/validate-math-review.cjs`。

## 3. 可选：独立浏览器工具

仓库还附带 [math-review-check.html](../tools/math-review-check.html)。它与命令行使用同一套校验逻辑，支持粘贴、选择多个文件、检查及下载合并JSON，不联网传送资料，也不自动保存。修改输入后，旧下载结果会失效。

该文件是独立HTML，**本PR没有为它开通GitHub Pages或发布在线站点**。GitHub Raw页面显示的是源码，不是运行界面。电脑可以用浏览器打开下载后的文件；iPad“文件”的快速预览可能不执行JavaScript，不能保证点开即运行。若已有可信的HTTPS静态托管，可以原样放置这个单文件后在Safari访问；不愿设置托管时使用上面的ChatGPT执行路径即可。不要把私人JSON作为公开仓库文件上传。

## 4. 导入现有复习台

1. 先在复习台导出一份完整备份，保留自己的笔记和标记。
2. 使用支持`math-review / schemaVersion:2`的复习台，打开“导入章节资料”，选通过检查的JSON，或把JSON本体贴进“粘贴JSON”，点击预览。
3. 核对学科、章节、新增与更新数量；同ID更新应对应原来的内容。确认后导入。
4. 检查一条公式、一条母题、一条自测和一条跨章联系，确认自己实际使用的前端版本兼容。
5. 导出时选**“资料JSON/全部资料”**。不要选“完整备份”作为插件输入。后者是`math-review-backup`，插件不直接接收。

导出单章可能把跨章related的目标留在外面；要保留跨章网络，应导出包含相关章节的全部资料，重新跑一次检查。更新同一节点时提供完整节点，不能只给一句补充。

若当前站点只接受`math-review-chapter`，那是另一套协议，不能改后缀或只改format强行导入。此时通过校验的math-review v2资料仍可直接交给现有数学学习桥；不要声称已适配未知旧站点。

## 5. 导入数学学习桥

在Obsidian打开命令面板，搜索“数学学习桥：导入复习资料”，选择通过检查的资料JSON，预览后点击“导入到Obsidian”。打开`数学学习桥/首页.md`，进入学科和章节。

- 章节目录与Canvas展示树，跨章节联系在条目笔记的“关联内容”中。
- 自测答案可折叠。自己的理解写在末尾“我的笔记”。
- 相同稳定ID重复导入会更新，个人笔记按现有插件规则保留；若手改导入区与来源更新冲突，新版本进入`_冲突`。
- 插件是单向导入；Obsidian里的修改不会自动写回复习台，也不会因导入讲解而变成“已经独立掌握”。

这次验证包括导入器和模拟Vault的自动测试；尚未在真实iPad/Obsidian上做设备验证，首次请在测试笔记库试导入示例。
